## 🚀 My Projects

### Task 1: EduLearn — Responsive Landing Page

I created a modern landing page for an online learning platform.

**Features:**

* Responsive design for desktop and mobile
* Hero section and course cards
* Learning paths and service sections
* Call-to-action buttons

### Task 2: Interactive Portfolio Website

I developed a personal portfolio website to showcase developer skills and projects.

**Features:**

* Introduction and skills section
* Project cards and timeline
* Interactive project filters
* Light and dark themes
* Contact form that opens an email draft

### Task 3: TaskMaster — To-Do Application

I built a simple task management app to help users organize their daily activities.

**Features:**

* Add and delete tasks
* Mark tasks as completed
* Filter tasks by status
* Clear completed tasks
* Save tasks using browser Local Storage

### Task 4: SkyPulse — Weather Dashboard

I developed a weather dashboard that displays weather information for a searched city.

**Features:**

* Search for a city
* Display current weather conditions
* Show humidity, wind speed, and cloud cover
* Display a five-day weather forecast
* Retrieve weather data using Open-Meteo APIs

## 🛠️ Technologies Used

* HTML5

* Browser Local Storage
* Open-Meteo APIs
* Visual Studio Code

## ▶️ How to Run the Projects

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required task folder.
4. Run `index.html` using the Live Server extension.
5. For the weather app, make sure your device is connected to the internet.

The SkyPulse Weather Dashboard uses Open-Meteo geocoding and weather forecast APIs. An internet connection is required to retrieve weather data. This demo does not require an API key.
